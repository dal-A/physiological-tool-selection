# 生理信号工具选择：代码说明

这是论文《质量感知工具选择与选择性生理报告：受试者隔离的多队列评价》对应的科研代码发布副本。

算法、配置和测试保留最终投稿材料中的版本。根目录英文 README 提供安装、索引解压、测试、full 实验及绘图命令。

1. `02_Code/physiological_tool_selection`：信号读取与预处理、传统模型和 CNN、质量门控、工具调用、保形预测、变化点监测、训练与测试。
2. `02_Code/P10_statistical_analysis`：人员级统计、置信区间、配对比较、敏感性分析和结果图。
3. `02_Code/P12_publication_figures_20261012_v1`：流程图及报告比例—损失图的生成代码。
4. `03_Data/qualified_indices.zip`：固定样本和窗口索引。网页上传时保持 ZIP；下载代码后按 README 解压才能运行测试和实验。
5. `figure_inputs`：绘图所需的最新统计表、字体及字体许可。
6. `docs`：数据官方来源、所需目录结构和复现说明。

本包提供代码与索引；完整 full 结果、预测和模型在论文的完整研究材料中。重新运行 full 还需按原资格流程准备原始数据，特别是 VitalDB 的原生配对窗口文件。仅从官方网站下载原始文件，不会自动得到本项目所需的全部中间文件。

原始数据不随仓库发布。研究软件的开源许可证尚未选定，不能把“能看到代码”理解为已经授予 MIT 等开源许可。字体使用单独的 SIL Open Font License。论文正式出版 DOI 和仓库网址确定后，可补充 CITATION.cff 与 README。
